Every result is judged against a bar set in advance.

Preregistered Money researches trading strategies the way a clinical trial is
run: the hypothesis, the data, the cost model, and the pass criteria are written
down and sealed with a git commit before the decisive run. The commit SHA is
the seal, git is the notary, and anyone can diff the preregistration against
the final run and verify nothing moved.

The deliverable is not a tip. It is a multi-year public scoreboard of what got
confirmed, what got falsified, and what the pinned record actually does —
backtests, run configs, and the video pipeline all public, with the agent
prompts that produce them. Falsification is a success state: the credibility is
built on what we didn't fudge.

Educational content, not investment advice.
